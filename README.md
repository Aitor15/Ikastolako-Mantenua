# Ikastolako Mantenua

Salbatore Mitxelena ikastolako mantentze-lanen aplikazioa.

- `index.html` — aplikazioa
- `config.js` — Firebase-ren konfigurazioa (itsatsi zurea hemen)
- `manifest.webmanifest`, `sw.js`, ikonoak — iPhone-ko hasierako pantailan instalatzeko

Datuak Firebase Firestore-n gordetzen dira, eta baimendutako Google kontuek bakarrik ikus ditzakete.
